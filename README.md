Калькулятор скидок (Discount Calculator)

Консольная программа на Python для быстрого расчёта итоговой цены товара
с учётом скидки. Без сторонних библиотек.

## Возможности

- Расчёт итоговой цены, суммы скидки и экономии
- Проверка корректности ввода (цена > 0, скидка 0–100 %)
- Округление до копеек (2 знака)
- Понятные сообщения об ошибках — программа не падает
- Команды `calc` (расчёт) и `exit` (выход)

## Запуск

Требуется Python 3.7+.

```bash
python discount_calculator.py
